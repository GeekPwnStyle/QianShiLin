# GSS 手工入库页面核对与实现边界

核对来源：2026-11-17 登录后的 GSS 菜单“采购 → 手工入库”（只读观察）。

## 原系统页面

- 表头：必选供应商、业务日期、预计收货时间、结算类型（本店结算/总店结算，当前账号不可改）、第三方单号、订单备注、供应商备注、附件。
- 选品：输入或扫描商品标/门店标，手选商品。
- 明细：品类、品牌、系列、规格型号、商品进货价、可编辑进货价、可编辑零售价、可编辑数量、金额、可编辑商品备注；可切换镜片合并。
- 汇总：运费、商品总数、商品金额、总金额。
- 操作：批量修改、重置、保存并可打印一物一码标。

## 当前实现

- 独立页面、门店范围内的入库草稿列表、搜索、分页、导出当前页、草稿详情。
- 草稿开单支持供应商、日期、结算方式、第三方单号、备注、运费、手选商品及逐行价格/数量/备注；金额实时计算。
- PostgreSQL `purchase.manual_inbound_drafts` / `manual_inbound_lines` 保存草稿，API 验证门店范围和制单权限。
- 草稿不会更新库存、采购单、应付账款。商品选择仍使用演示目录，页面明确提示。

## 待核对与接通

- 商品主数据、条码/UDI 解析、附件存储、镜片合并与批量编辑的实际规则。
- 原系统保存后的状态、打印流程、入库批次与库存流水、结算和应付关系。
- 结算类型能否修改及其门店级配置权限。

以上规则未确认前，不应把草稿提交为正式入库，也不应改变库存或财务余额。
