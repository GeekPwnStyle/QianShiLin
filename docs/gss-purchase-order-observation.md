# 采购订货单页面核对记录

来源：2026-11-17 在 GSS 零售后台登录后，通过采购 → 采购订货单查看；只进行只读操作，没有保存原系统单据。

列表有“本店采购订货单”“分店采购订货单”两个标签。工具栏包括新增（系列/单品）、批量确认、批量录入快递信息、订单明细、订单合并、导出、本周、本月、关键词搜索、筛选搜索。列表字段包括创建时间、状态、总店确认、订货数量、验收数量、类型、制单人、供应商、备注、订单来源、供应商备注、关联采购单、供应链、快递信息、操作和单号；下方有本页小计与分页。当前账号在本店列表中无数据，未见实际行内操作。

单品和系列新建入口都打开“采购订货单开单”。可见供应商、创建日期、来源单号（禁用）、备注、手选商品、供应商备注（禁用）、快递信息；商品明细为商品名称、品类、品牌、系列、规格型号、订货数量、验收数量、备注，底部有重置和保存。手选商品面板支持按名称/品牌/型号/色号/系列/折射率/售价搜索，按品类、品牌、系列、折射率筛选，分页和选择。

目标项目本轮实现：授权门店列表、搜索、导出当前页、单品/系列草稿开单、演示商品选择、数量和备注编辑、草稿保存及详情，PostgreSQL 持久化和服务端门店范围校验。批量确认、快递信息、合并、正式提交、验收及其状态流转未在原系统执行，规则仍待核实。
